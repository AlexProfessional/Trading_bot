# 🚀 Alpha-Pulse: AI Crypto Trading Bot

**Alpha-Pulse** — это продвинутый асинхронный торговый бот для криптовалютных фьючерсов (Bybit). Бот сканирует рынок, находит аномалии волатильности, анализирует их с помощью нейросети (DeepSeek) и совершает виртуальные сделки (Paper Trading) с жестким контролем рисков.

## 🌟 Ключевые возможности

- **Сканер рынка:** Автоматически отбирает Топ монет по объему торгов за 24 часа.
- **Асинхронный сбор данных:** Быстрое получение цен через API биржи (HTTP/WebSocket).
- **ИИ-Аналитика:** Интеграция с LLM (DeepSeek через ProxyAPI) для анализа трендов и генерации торговых сигналов (BUY / SELL / WAIT).
- **Риск-менеджмент:** Автоматический расчет **Стоп-лоссов (SL)** и **Тейк-профитов (TP)** для каждой сделки.
- **Плечо (Leverage):** Безопасное виртуальное плечо x3 для увеличения потенциальной прибыли.
- **Telegram-интерфейс:** Полное управление ботом через удобные кнопки в Telegram (Запуск/Остановка) и мгновенные отчеты о каждой сделке.
- **База данных:** Хранение истории цен и виртуальных сделок в SQLite.

## 🛠 Технологический стек

- **Python 3.11+**
- **CCXT** (асинхронная работа с API биржи Bybit)
- **OpenAI SDK** (для интеграции с DeepSeek/ProxyAPI)
- **pyTelegramBotAPI** (интерфейс управления)
- **Flask** (веб-хуки для работы на хостинге)
- **SQLite** (хранение данных)
- **Render** (облачный хостинг)
